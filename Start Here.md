# Start Here 👋

Welcome! This vault is pre-configured so you can start working immediately. Here's how everything fits together.

## First launch

When you open this vault for the first time, Obsidian will ask if you **trust the author** — choose **Trust author and enable plugins**. All the plugins below are open-source community plugins and are already installed and configured.

If you would rather not do the setup by hand, **Claude Code** can clone this vault, place it where you want it and adjust settings for you — ask it in plain words. It cannot click the trust dialog above, so that one stays with you.

## Daily workflow

1. **Press `Cmd/Ctrl + D`** — opens (or creates) **today's daily note** in `Journal/`, pre-filled with your habit checklist and hourly time-blocking table. Edit `Templates/Daily Note Template.md` to make it yours.
2. **Weekly review** — the Calendar plugin (right sidebar) lets you click a week number to create a **weekly note** for reflection: what went well, what could be better, gratitude.
3. **Kanban boards** — see `Kanban/k_ Example Project.md`. Create new boards with the command palette (`Cmd/Ctrl + P` → "Kanban: Create new board"). The convention here is to prefix board names with `k_`.
4. **GTD** — `GTD/My GTD Board.md` follows the Getting Things Done flow: Clarify → Organize → Reflect → Engage. Use `Templates/GTD.md` to start a new one (insert templates with `Cmd/Ctrl + P` → "Templates: Insert template").

## Folder map

| Folder       | Purpose                                        |
| ------------ | ---------------------------------------------- |
| `Journal/`   | Daily and weekly notes land here automatically |
| `Kanban/`    | Kanban project boards (`k_` prefix)            |
| `GTD/`       | Getting Things Done boards                     |
| `Templates/` | Note templates (daily, weekly, GTD)            |
| `Excalidraw/`| Drawings and sketches                          |
| `Kindle/`    | Kindle highlights (if you connect the plugin)  |

## Useful hotkeys

| Hotkey             | Action                              |
| ------------------ | ----------------------------------- |
| `Cmd/Ctrl + D`     | Open today's daily note             |
| `Cmd/Ctrl + Enter` | Cycle checkbox state on a list item |
| `Cmd/Ctrl + G`     | Open local graph for current note   |
| `Cmd/Ctrl + R`     | Switch text direction (RTL/LTR)     |
| `Cmd/Ctrl + P`     | Command palette — search any action |

## What's installed

**Theme:** AnuPpuccin (with the Style Settings plugin for customization).

**Key plugins:**
- **Periodic Notes + Calendar** — daily/weekly journaling
- **Kanban** — drag-and-drop project boards
- **Tasks** — task tracking with due dates and queries across the whole vault
- **Templater + Templates** — note templates
- **Dataview** — query your notes like a database
- **Excalidraw** — sketching and diagramming
- **Outliner** — better list editing
- **Advanced Slides** — turn notes into presentations
- **RTL support** — Arabic/Hebrew text direction switching
- **LanguageTool** — grammar checking
- **Pandoc / Enhancing Export** — export to Word, PDF, LaTeX, and more (requires [Pandoc](https://pandoc.org/installing.html) installed on your machine)
- **PlantUML** — text-based diagrams
- **Financial Statement** — generate financial statement templates
- **Kindle Highlights** — sync your Kindle highlights (sign in via plugin settings)
- **Chesser** — chess boards in notes
- **Quick LaTeX, Table Generator, Checklist, Cycle Through Panes, Syntax Highlighting**

Make it yours — edit the templates, delete what you don't use, and enjoy. 🚀
